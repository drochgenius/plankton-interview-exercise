# Interview Instructions

## Basic Expectations

You should be familiar with:

- Git and Github
- TypeScript, Node.js, React, CSS and Sass/SCSS
- Container technologies (Docker / Podman)
- REST services and databases
- JavaScript testing frameworks
- Code bundlers such as ViteXXX

## Before the Interview

- You have access to the repository code in advance.
- Clone the repo and set up the development environment as described in the README, on your personal computer.
  - All required tools are free and open source.
- When you join the interview, the application must already be running in your local browser.
- Recommended IDEs: Visual Studio Code or WebStorm.
- You may use any tool you like, including AI coding agents.

## During the Interview

- You will receive a user story for a new feature: a description plus acceptance criteria.
- Share your screen at all times, including any prompting or interaction with AI.
- Use any tool you like, as long as you share it and disclose it openly.
- Ask the interviewers questions or request help whenever you need.
- Complete the feature implementation.
- Create a branch and open a pull request for the feature.
  - The PR must include a clear description of your contribution.
- **Stretch goal:** write unit tests covering the new feature.

## Goal

- Demonstrate the working feature locally.
- Open a pull request with the feature contribution.
